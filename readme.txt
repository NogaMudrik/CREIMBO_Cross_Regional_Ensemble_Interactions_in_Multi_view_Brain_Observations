This is the core code for the CrEIMBO method.

main_CREIMBO.py: Storing the main functions.

run_CREIMBO.py: Calling the model and saving. 

synthetic_create_low_regions_simple_example4.py: Creating the synthetic data.

open_human_data_multi_regional_000469.py: Loading and pre-processing of human data.

The human data is taken from :
Kyzar M, Kamiński J, Brzezicka A, Reed CM, Chung JM, 
    Mamelak AN, Rutishauser U. Dataset of human-single neuron activity during a Sternberg working memory task. Sci Data. 2024 Jan 18;11(1):89. doi: 10.1038/s41597-024-02943-8. PMID: 38238342; PMCID: PMC10796636.
